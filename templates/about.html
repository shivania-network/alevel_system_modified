About This System

A-Level Academic Pathway Recommendation System — BTech Capstone Project, Rwanda Polytechnic

What Is This System?

The A-Level Academic Pathway Recommendation System is a web-based application that uses machine learning to recommend the most suitable A-Level combination for O-Level students at G.S NYAKINAMA I TSS, Musanze, Rwanda.

Many students choose their A-Level pathway based on peer influence or guesswork rather than their actual academic strengths. This system provides an objective, data-driven recommendation by analysing a student's O-Level grades across eleven subjects alongside their personal preferences, career goals, and talents — giving every student a fair, personalised guidance tool.

How the Recommendation Works

The system uses a Random Forest Classifier — an ensemble machine learning algorithm that builds 300 decision trees and combines their outputs for a stable, accurate prediction.
